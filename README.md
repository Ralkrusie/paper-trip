# 行迹 · 轻量行程规划

> Xingji — a zero-build, pure front-end trip planner built on AMap.

一个**零部署、纯前端**的个人行程规划工具：在高德地图上收集地点、编排多日行程、画路线、做统计。
数据保存在浏览器本地（localStorage），导出一个 JSON 就是完整备份。

> 本项目由一个课程作业原型（“沪上研学参访动态网页地图” v3）重做而来：保留了高德地图封装、聚焦飞行动画、按序浏览、设计色系等组件，退役了粒子地球开场与书架/翻书视觉，重构为通用规划工具。旧版原型代码与文档未随仓库发布。

## 功能

- **地图工作台**：暗黑 / 标准 / 卫星三种风格、2D / 3D 切换、比例尺、飞行定位动画
- **添加地点**：
  - 地图**左上角常驻搜索框**：地点名 + 地址双通道（地址可精确到门牌号，结果带「门牌号 / 地点」标签）；点结果行在地图上预览，点 ＋ 直接加入当前天
  - 点击地图空白处直接落点新建（自动补全地址）
  - 新建 / 编辑弹窗内同样支持搜索带上坐标
  - 手动输入坐标 / 地址（“地图选点”可在地图上拾取坐标）
- **地点库**：分类筛选（交通/住宿/餐饮/活动）、关键词搜索、使用情况标记
- **多日编排**：任意增删天数（日期自动排序与顺延）；地点加入某天（同一天可重复，如「入住酒店 / 回酒店」）、跨天移动；**拖动卡片排序（手机长按卡片拖动）**；每站可填时间、停留时长、备注
- **通勤方式**：点两站之间的「通勤行」选步行 / 骑行 / 驾驶 / 出租 / 公交 / 地铁 / 动车 / 其他，除「其他」外按两站直线距离自动估算时长（含公交/地铁/动车的候车缓冲），可加备注（如「地铁 1 号线」）
- **时间轴推算**：填了时间的项 = 硬性时刻（如演出 19:30），留空的项按「上一站 + 停留 + 通勤」自动推算；迟到会自动标红
- **软删除**：不想要的站点先「移除」——变灰沉到当天末尾，不计入时间轴/地图/统计，随时可恢复，也可彻底删除
- **地图联动**：两站之间逐段画虚线，**颜色随「这段路要走的次数」加深**（玫粉 1 次 → 粉红 2 次 → 玫紫 3 次 → 紫 4 次+，粉色系渐变，通勤行里标有 ×N）；白色**方向箭头**沿全程路线循环流动指示行进方向；圆形编号 = 当天停留顺序；**标记颜色与地点分类配色一致、大小随缩放自动变化**，悬停变半透明（未安排地点为同色小圆点）；点击标记/卡片互相联动；每站可一键唤起高德导航
- **按序浏览**：一键依次飞往当天每个站点
- **统计**：每日站点数、每日直线里程、分类分布（ECharts）
- **行程单导出**：一键生成**单文件离线 HTML**——手机关网也能看，站点里的「高德导航」链接可直接唤起地图 App，在电脑上 Ctrl/Cmd+P 可存为 PDF
- **行程须知**：顶栏 ✎ 填写住宿/退房/行李等备注，会写进行程单
- **数据管理**：导出 / 导入 JSON、清空一键重置
- **移动端**：底部抽屉式行程面板，路上随时查看

## 快速开始

方式一（推荐）：在项目根目录起一个静态服务器，然后访问它：

```bash
python -m http.server 8080
# 或 npx http-server -p 8080
```

```text
http://127.0.0.1:8080/
```

方式二：直接双击 `index.html`（使用 `file://` 打开）。大部分功能可用，但个别浏览器对本地文件的存储策略不同，长期使用建议用方式一。

## 部署到 GitHub Pages

纯静态站点，可直接用 GitHub Pages 免费托管：

1. 在 GitHub 新建仓库（如 `xingji-planner`），把本仓库推送上去
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存
3. 稍等 1–2 分钟，访问 `https://<用户名>.github.io/xingji-planner/`

> **安全提示**：高德 Key 写在前端代码里，托管后必然公开（纯前端地图应用都是如此）。建议到高德开放平台给 Key 配置**域名白名单**（加上你的 `*.github.io`），防止被盗用额度。

## 使用要点

1. 左上角搜索框搜**地点或地址**（如「汾阳路6号」，精确到门牌号）：点结果行 → 地图预览打点；点 ＋ → 加入当前天；附近已有地点会自动复用，不会建重复点
2. 也可以直接点击地图任意位置落点新建（自动补全地址）
3. 在「地点库」用 ＋ 把候选地点加入当前天；拖动卡片排序（手机长按卡片拖动）
4. 拖动卡片到顶部某一个日期标签上，即可跨天移动；行程项弹窗里也能改“所属天”
5. 行程项弹窗里：时间 = 硬性时刻（如 19:30 开演），留空自动推算；通勤方式点两站之间的「通勤行」设置（会按距离给出时长参考）
6. 点「▶ 浏览」按顺序预览当天路线；「路线总览」显示全部或当天的标记范围
7. 不需要的站点点 × 禁用（沉到当天末尾，可随时恢复）；顶栏「行程单」导出一页式行程表；「统计」看里程分布；「帮助」里有导出/导入/清空入口

## 数据与备份

- 存储位置：浏览器 `localStorage`，键名 `xingji.trip.v1`
- 换浏览器、换电脑、清理缓存**之前**，请先在「帮助 → 导出 JSON」备份
- 导入会**覆盖**当前全部数据；导入的旧版本数据会自动做兼容性清洗（丢弃失效引用、校正字段类型）

## 手机使用（出门不带电脑）

1. **主推：行程单离线 HTML**。点顶栏「行程单」下载一个单文件 HTML，用微信发给自己（文件传输助手）或传到手机，浏览器打开即可离线查看；每个站点的「高德导航到这里」可一键唤起高德 App
2. **实时使用（同一 Wi-Fi）**：电脑上运行静态服务器（如 `python -m http.server 8177`），手机浏览器访问 `http://<电脑局域网IP>:8177`（`ipconfig` 查 IP，首次需允许防火墙）。适合出发前在家最后检查，不适合在路上用（电脑不开时不可用）
3. **想要真正的手机实时同步**：把整个文件夹丢到任意静态托管（GitHub Pages / Netlify / Vercel）即可；数据也可随时用 JSON 导入导出迁移

## 高德地图配置

`js/amap.js` 顶部的两个常量对应你自己在高德开放平台申请的 Key：

```js
var AMAP_KEY = '...';
var AMAP_SECURITY_CODE = '...';
```

- 地图渲染只需 JS API 的 Key
- 「搜索高德地点」「自动补全地址」等在线服务依赖 Key 开通对应服务；服务不可用时界面会给出提示，核心的"手动加点 / 编排 / 统计"不受影响
- **坐标系说明**：工具全程使用高德坐标系（GCJ-02）。从 OSM / 谷歌地图等 WGS-84 来源复制坐标会偏移数百米，建议使用内置搜索或地图选点获取坐标

## 已知限制与后续方向

- 里程与通勤时长为**估算**（直线距离 ×1.3 绕路系数 ÷ 各方式均速，公交/地铁/动车额外加候车与进出站缓冲，取整到 5 分钟），未接入真实路径规划；真实出行请以高德导航为准
- 数据只在本机浏览器，暂无云端同步（导出/导入即备份方案）
- 导入为整体覆盖，暂无合并模式
- 地点暂不支持照片字段
- 搜索（POI 与地址解析）都是全国范围：同名地址很多（如各地都有“汾阳路6号”），结果已按**当前地图中心距离**排序；找外地地址时先把地图大致移到目标区域即可
