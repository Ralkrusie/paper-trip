# 拾途 Paper Trip · 微信小程序版

网页版的手机端形态：同一套数据结构与文案，界面重写为小程序（WXML/WXSS），
地图换用微信原生 `map` 组件（腾讯底图），真实路线来自高德 **Web 服务** REST 接口。

> 数据与网页版**双向互通**：网页版「导出 JSON」→ 小程序「设置 → 导入数据」粘贴即可；
> 反过来，小程序的导出备份也能粘贴回网页版导入。

## 快速开始

### 1. 导入项目

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 「导入项目」→ 目录选择本仓库的 **`miniprogram/`** 文件夹
3. AppID：没有账号就选「测试号」（`touristappid`），注册后换成自己的
4. 右上角「详情 → 本地设置」勾选 **「不校验合法域名」**（开发期必须，否则无法请求高德接口）

### 2. 配置高德 Key（获取真实路线）

1. 登录[高德开放平台控制台](https://console.amap.com/dev/key/app) → 应用管理 → 创建新应用
2. 添加 Key，**服务平台选「Web 服务」**（注意：不是 Web 端 JS API，两者不通用）
3. 复制 Key，在小程序「设置 → 高德『Web 服务』Key」里粘贴并保存
4. 保存后自动开始获取真实路线：时长取高德值、公共交通显示完整换乘链与换乘站

未配置 Key 时程序也能完整运行：路线退化为虚线直连 + 本地估算（含 1.3 倍绕路系数）。

### 3. 真机体验（可选）

开发者工具「预览」扫码即可在手机上体验；正式发布前可把同行朋友加为**体验成员**，
无需审核就能试用。正式发布需在公众平台提交审核（约 1–7 天）。

### 4. 发布前检查

- 公众平台 →「开发管理 → 开发设置 → 服务器域名」：把 **`https://restapi.amap.com`** 加入 **request 合法域名**
- `project.config.json` 里的 `appid` 换成自己的
- `urlCheck` 会随正式构建自动生效，无需修改

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss    入口、全局配置、全局样式（设计变量与网页版一致）
├── assets/                          标记图标与箭头（由 tools/gen_mini_assets.py 生成）
├── utils/
│   ├── store.js                     数据层：存储（wx storage）、时间轴、统计、导入导出
│   ├── format.js                    文案/格式化：通勤行文字、编号、颜色、日期标签
│   ├── amap.js                      高德 Web 服务封装（wx.request → restapi.amap.com）
│   └── routes.js                    路线服务：缓存、失败重试、订阅刷新
└── pages/
    ├── index/                       主页面：地图 + 抽屉（行程 / 地点 / 设置）
    ├── item/                        行程项编辑（含「到下一站」通勤设置）
    ├── place/                       地点编辑（搜索添加 / 地图点选 / 附近候选）
    └── stats/                       统计页
```

## 资源生成

标记图标（分类色圆形徽标、未安排小圆点、流动箭头）由纯 Python 脚本生成，无需 Pillow：

```bash
python tools/gen_mini_assets.py
```

## 静态自检

改完代码可先跑一遍仓库根目录的零依赖自检脚本（校验 JSON、页面四件套、事件绑定、require 路径）：

```bash
node tools/mini_check.js
```

没有装 Node 也没关系，可用微信开发者工具自带的 Node，例如：

```powershell
& "D:\Development\微信web开发者工具\node-18.exe" tools\mini_check.js
```

## 已知差异与后续优化

- **底图**：微信 `map` 组件底图为腾讯提供（GCJ-02 坐标系，与高德路线叠加一致）；
  暗黑/标准等自定义风格需要「个性化地图」能力（付费），当前仅提供卫星开关与 3D 视角。
- **箭头动画**：受小程序 setData 节流限制（约 120ms 一次），观感比网页版略“跳”；
  后续可改用 `MapContext.moveAlong` 做原生平滑轨迹，配合 `interpolatepoint` 事件驱动镜头。
- **数字标签居中**：`label.anchorX/anchorY` 为按字号估算的近似值，真机若略偏可在
  `pages/index/index.js` 的 `refreshMap` 里微调。
- **地图个性化样式**：如后续开通，可在 `map` 组件加 `subkey` 与 `layer-style` 实现。
