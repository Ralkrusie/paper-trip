          使用说明

          1. 添加地点：点击地图空白处会列出附近地址（门牌号 / 周边地点，含距离），选一个即精确落点、名称自动预填（可编辑）；也可以用左上角搜索框搜地点或地址（地址可精确到门牌号，选结果看预览，点 ＋ 存入地点库）。
          2. 编排行程：在「地点库」点 ＋ 选择加入行程的某一天（同一天可重复加，例如「入住酒店 / 回酒店」）；拖动卡片排序（手机上长按卡片即可拖动），拖到别的日期标签上即可跨天移动。
          3. 通勤方式：点两站之间的「通勤行」选步行 / 骑行 / 驾驶 / 出租 / 公交 / 地铁 / 动车 / 其他——除「其他」外都会按两站直线距离（×1.3 绕路系数）与各方式均速估算时间，可加备注（如地铁几号线）。
          4. 路线颜色：两站之间连线的颜色表示这段路在行程里需要走的次数——浅橙 = 1 次，橙 = 2 次（如往返酒店），深橙 = 3 次，棕橙 = 4 次及以上（通勤行会标注 ×N）；白色小箭头沿路线循环流动，指示行进方向；标记编号为**全程统一字母序号**（A、B、C…，超过 26 站后接 27、28…，跨天连续不重置），各天路线首尾相连；地图标记会随缩放自动放大缩小。
          5. 移除与恢复：点 ⊖ 会移除该站点（变灰沉到当天最下方，不再计入时间轴、地图与统计），随时可恢复或彻底删除。
          6. 时间轴：行程项填了时间 = 硬性时刻（如演出 19:30）；留空则按「上一站 + 停留 + 通勤」自动推算。卡片上圆点后的时间即推算结果，迟到会标红。
          7. 手机查看：点「行程单」导出离线 HTML 发到手机（微信文件传输助手即可），离线可看，站点里的「高德导航」可一键唤起地图 App。同一 Wi-Fi 下，手机浏览器也能访问电脑的局域网地址实时使用。
          8. 数据保存：数据自动保存在浏览器本地（localStorage）。换浏览器或清理缓存前，请先导出 JSON 备份。

          数据管理
          高德地图未能加载，请检查网络或 Key 配置。地点数据仍可编辑，但地图相关功能暂不可用。
